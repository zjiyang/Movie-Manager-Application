# 🎬 Movie Collection Manager 

## What can this do?
This application helps users keep track of movies they’ve watched and those they plan to watch. It offers features such as:
- Record movies users have watched or plan to watch
- Include additional information, such as:
    - When they were watched
    - How many times they’ve been watched
    - Who they were watched with
- Add personal notes or reviews
- Organize movies by genre or custom labels

## Who is this for?
This tool is designed for movie enthusiasts, casual viewers, or anyone looking for a simple way to manage their movie list. It’s useful for tracking viewing history, noting favorite films, and organizing titles into meaningful customized categories.

## Why choose this project?
This project provides a practical approach to improving movie organization. Adding features like tracking watch dates, frequency, and companions makes it more versatile. At the same time, it offers the chance to develop a well-structured, user-friendly application.
